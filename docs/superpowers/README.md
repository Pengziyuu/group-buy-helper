# 歷史設計與實作紀錄

此目錄保存團購小幫手過去的設計規格與階段計畫，供追溯決策，不是目前的待辦清單或最新功能說明。原始連結暫予保留；已完成的步驟、舊路由、舊測試數及舊預設值可能與現行程式不同。

- [`specs/`](specs/)：當時的設計規格與取捨。
- [`plans/`](plans/)：各階段拆解、驗證步驟與結果。

閱讀順序：先看專案根目錄的 [`README.md`](../../README.md)（公開介紹）、[`docs/ARCHITECTURE.md`](../ARCHITECTURE.md)（現行資料流）與 [`docs/AI_AGENT_HANDOFF.md`](../AI_AGENT_HANDOFF.md)（維護規則）；若與此處歷史文件衝突，以最新程式、測試、migration 和正式環境讀回結果為準。**不要照舊計畫中的 SQL、刪檔或部署指令直接對正式環境操作。**
